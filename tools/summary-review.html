Element wording review

Rewrite each Objective Element in your own words, then mark it reviewed. The site shows only reviewed summaries; anything unreviewed falls back to the code and chapter alone.

Write from the requirement, not from the sentence. Read the element, look away, and write what a hospital actually has to do. A reworded copy is still a copy, and it reads worse. Check each against the published standard you have legitimate access to before ticking reviewed — the wording currently stored may not be exact.
